# Tema 4: Generación de Servicios en Red y Seguridad

Esta unidad final abordará la creación de servicios basados en protocolos, la gestión de múltiples clientes y, fundamentalmente, los principios y prácticas de seguridad.

## Contenidos

1. Implementación de Protocolos Estándar y Servicios
   - Análisis y uso de librerías para implementar protocolos estándar (HTTP, FTP, etc.). 
   - Programación de clientes y servidores de protocolos estándar. 
   - Desarrollo y prueba de servicios de comunicación en red.

2. Servicios Concurrentes y Disponibilidad
   - Requisitos para crear servicios capaces de gestionar varios clientes concurrentes. 
   - Mecanismos para posibilitar la comunicación simultánea. 
   - Verificación de la disponibilidad del servicio.

3. Fundamentos de la Programación Segura y Criptografía
   - Principios y prácticas de programación segura (validación de entradas, seguridad por diseño). 
   - Análisis de las principales técnicas y prácticas criptográficas (cifra simétrica/asimétrica, hashing, firmas digitales). 
   - Protocolos criptográficos (SSL/TLS).

4. Control de Acceso, Almacenamiento y Transmisión Segura
   - Definición e implantación de políticas de seguridad (autenticación, autorización). 
   - Gestión de usuarios basada en roles. 
   - Protección de la información almacenada (encriptación de datos). 
   - Métodos para asegurar la información transmitida. 
   - Programación de aplicaciones que utilicen sockets seguros (SSL/TLS).

5. Depuración y Documentación de Aplicaciones Seguras y Servicios
   - Depuración de servicios en red y aplicaciones seguras. 
   - Documentación de políticas e implementaciones de seguridad.

### Ejercicio 1: Hashing de Contraseñas con Salt (PBKDF2)
**Enunciado:** Crea un programa que simule el registro y login de un usuario.
1. **Registro:** Pide una contraseña, genera un "salt" aleatorio, calcula el hash de la contraseña con el algoritmo **PBKDF2** usando ese salt y muestra los valores guardados.
2. **Login:** Pide la contraseña de nuevo, recupera el salt generado anteriormente, recalcula el hash y verifica si coincide.
**Requisitos:**
- Usar `SecretKeyFactory` con el algoritmo `PBKDF2WithHmacSHA256`.
- Usar `SecureRandom` para generar el salt.
- Comparar los hashes con `MessageDigest.isEqual()` (comparación en tiempo constante).

:::tip ¿Por qué no basta con SHA-256?
SHA-256 está diseñado para ser **rápido**, y eso es un problema para las contraseñas: una tarjeta gráfica puede calcular miles de millones de hashes SHA-256 por segundo, lo que permite probar contraseñas por fuerza bruta. PBKDF2, BCrypt o Argon2 son funciones **deliberadamente lentas** (aplican el hash miles de veces), lo que hace inviable ese ataque. OWASP recomienda al menos 600.000 iteraciones para PBKDF2-HMAC-SHA256.
:::

<details>
<summary>Solución</summary>

```kotlin title="PasswordHasher.kt"
import java.security.MessageDigest
import java.security.SecureRandom
import java.util.Base64
import java.util.Scanner
import javax.crypto.SecretKeyFactory
import javax.crypto.spec.PBEKeySpec

data class UsuarioDB(val salt: String, val hash: String)

const val ITERACIONES = 600_000
const val LONGITUD_HASH_BITS = 256

fun main() {
    val scanner = Scanner(System.`in`)
    
    // --- FASE DE REGISTRO ---
    println("=== REGISTRO ===")
    println("Introduce tu nueva contraseña:")
    val passwordRegistro = scanner.nextLine()
    
    // 1. Generar Salt
    val saltBytes = ByteArray(16)
    SecureRandom().nextBytes(saltBytes)
    
    // 2. Hashear
    val hashBytes = hashear(passwordRegistro, saltBytes)
    
    // Simular guardado en BD (en Base64 para poder guardarlo como texto)
    val encoder = Base64.getEncoder()
    val usuarioGuardado = UsuarioDB(encoder.encodeToString(saltBytes), encoder.encodeToString(hashBytes))
    println("Usuario registrado. Guardado en BD -> Salt: ${usuarioGuardado.salt}, Hash: ${usuarioGuardado.hash}")
    
    // --- FASE DE LOGIN ---
    println("\n=== LOGIN ===")
    println("Introduce tu contraseña para entrar:")
    val passwordLogin = scanner.nextLine()
    
    // 3. Verificar: recalcular el hash con el MISMO salt
    val decoder = Base64.getDecoder()
    val hashIntento = hashear(passwordLogin, decoder.decode(usuarioGuardado.salt))
    val hashGuardado = decoder.decode(usuarioGuardado.hash)
    
    // MessageDigest.isEqual compara en tiempo constante (evita ataques de temporización)
    if (MessageDigest.isEqual(hashIntento, hashGuardado)) {
        println("¡Acceso CONCEDIDO!")
    } else {
        println("¡Acceso DENEGADO!")
    }
}

fun hashear(password: String, salt: ByteArray): ByteArray {
    val spec = PBEKeySpec(password.toCharArray(), salt, ITERACIONES, LONGITUD_HASH_BITS)
    try {
        val factory = SecretKeyFactory.getInstance("PBKDF2WithHmacSHA256")
        return factory.generateSecret(spec).encoded
    } finally {
        spec.clearPassword() // Borrar la contraseña de memoria lo antes posible
    }
}
```
</details>

### Ejercicio 2: Cifrado Simétrico de Texto (AES-GCM)
**Enunciado:** Implementa una utilidad que permita cifrar y descifrar una frase utilizando el algoritmo AES en modo GCM.
**Requisitos:**
- Generar una clave AES de 256 bits.
- Generar un vector de inicialización (IV) aleatorio de 12 bytes para cada cifrado.
- Mostrar el mensaje original, el mensaje cifrado (en Base64 para que sea legible) y el mensaje descifrado.

:::warning No usar `Cipher.getInstance("AES")`
Si solo indicamos `"AES"`, Java utiliza por defecto el modo **ECB**, que cifra cada bloque de 16 bytes de forma independiente: dos bloques iguales producen el mismo resultado cifrado, lo que deja ver patrones de los datos originales. Hay que indicar siempre el modo completo. **GCM** es el recomendado, porque además de cifrar detecta si el mensaje ha sido manipulado (cifrado autenticado).
:::

<details>
<summary>Solución</summary>

```kotlin title="CifradoAES.kt"
import java.security.SecureRandom
import java.util.Base64
import javax.crypto.Cipher
import javax.crypto.KeyGenerator
import javax.crypto.SecretKey
import javax.crypto.spec.GCMParameterSpec

const val IV_BYTES = 12
const val TAG_BITS = 128

fun cifrar(texto: String, clave: SecretKey): ByteArray {
    val iv = ByteArray(IV_BYTES).also { SecureRandom().nextBytes(it) } // IV nuevo en cada cifrado
    val cipher = Cipher.getInstance("AES/GCM/NoPadding")
    cipher.init(Cipher.ENCRYPT_MODE, clave, GCMParameterSpec(TAG_BITS, iv))
    // El IV no es secreto: lo guardamos delante del texto cifrado para poder descifrar
    return iv + cipher.doFinal(texto.toByteArray())
}

fun descifrar(datos: ByteArray, clave: SecretKey): String {
    val iv = datos.copyOfRange(0, IV_BYTES)
    val cifrado = datos.copyOfRange(IV_BYTES, datos.size)
    val cipher = Cipher.getInstance("AES/GCM/NoPadding")
    cipher.init(Cipher.DECRYPT_MODE, clave, GCMParameterSpec(TAG_BITS, iv))
    return String(cipher.doFinal(cifrado)) // Lanza AEADBadTagException si los datos se han alterado
}

fun main() {
    val mensajeOriginal = "Este es un mensaje ultra secreto"
    println("Original: $mensajeOriginal")

    // 1. Generar Clave
    val keyGen = KeyGenerator.getInstance("AES")
    keyGen.init(256)
    val secretKey = keyGen.generateKey()

    // 2. Cifrar
    val datosCifrados = cifrar(mensajeOriginal, secretKey)
    println("Cifrado (Base64): ${Base64.getEncoder().encodeToString(datosCifrados)}")

    // 3. Descifrar
    println("Descifrado: ${descifrar(datosCifrados, secretKey)}")
}
```
</details>

### Ejercicio 3: Consumo de API REST con HttpClient
**Enunciado:** Utiliza la clase `java.net.http.HttpClient` (disponible desde Java 11) para hacer una petición GET a una API pública (por ejemplo, `https://jsonplaceholder.typicode.com/todos/1`) y mostrar el JSON recibido.
**Requisitos:**
- La petición debe ser asíncrona o síncrona.
- Imprimir el código de estado y el cuerpo de la respuesta.

<details>
<summary>Solución</summary>

```kotlin title="ClienteAPI.kt"
import java.net.URI
import java.net.http.HttpClient
import java.net.http.HttpRequest
import java.net.http.HttpResponse

fun main() {
    val client = HttpClient.newHttpClient()
    
    val request = HttpRequest.newBuilder()
        .uri(URI.create("https://jsonplaceholder.typicode.com/todos/1"))
        .GET()
        .build()

    println("Enviando petición...")
    
    val response = client.send(request, HttpResponse.BodyHandlers.ofString())
    
    println("Código de estado: ${response.statusCode()}")
    println("Cuerpo de la respuesta:")
    println(response.body())
}
```
</details>

### Ejercicio 4: Servidor HTTP con Control de Acceso (Token)
**Enunciado:** Crea un servidor HTTP simple (usando `HttpServer`) que proteja una ruta `/secreto`.
- Si el cliente envía la cabecera `Authorization: Bearer 12345`, el servidor responde con información secreta (código 200).
- Si no envía la cabecera o el token es incorrecto, responde con "Acceso Denegado" (código 401 Unauthorized).
- Puedes probarlo con `curl -H "Authorization: Bearer 12345" http://localhost:8000/secreto`.
**Requisitos:**
- Usar `com.sun.net.httpserver.HttpServer`.

<details>
<summary>Solución</summary>

```kotlin title="ServidorProtegido.kt"
import com.sun.net.httpserver.HttpServer
import java.net.InetSocketAddress

fun main() {
    val server = HttpServer.create(InetSocketAddress(8000), 0)
    
    server.createContext("/secreto") { exchange ->
        // Leer cabeceras
        val authHeader = exchange.requestHeaders.getFirst("Authorization")
        
        val respuesta: String
        val codigo: Int
        
        if (authHeader == "Bearer 12345") {
            codigo = 200
            respuesta = "¡ACCESO CONCEDIDO! El código nuclear es 0000."
        } else {
            // 401: no se ha podido autenticar al cliente.
            // (403 Forbidden se usa cuando el cliente SÍ está autenticado pero no tiene permiso)
            codigo = 401
            exchange.responseHeaders.add("WWW-Authenticate", "Bearer")
            respuesta = "ACCESO DENEGADO. Token inválido o ausente."
        }
        
        // La longitud debe ir en BYTES, no en caracteres ("¡" ocupa 2 bytes en UTF-8)
        val bytes = respuesta.toByteArray()
        exchange.responseHeaders.add("Content-Type", "text/plain; charset=utf-8")
        exchange.sendResponseHeaders(codigo, bytes.size.toLong())
        exchange.responseBody.use { it.write(bytes) }
    }
    
    println("Servidor protegido escuchando en puerto 8000...")
    server.start()
}
```
</details>
